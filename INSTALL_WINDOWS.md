# Install on Windows

Download `MosaicEarth-Desktop-0.4.1-x64-Setup.exe` from [Desktop](https://app.mosaicearth.app/en/Desktop), using the account that purchased Desktop or has an eligible Studio plan. Compare its SHA-256 with the published manifest. This is a native graphical NSIS wizard, with no manual `.bat` step. It is unsigned; Windows can display an unknown-publisher/reputation prompt.

Use Windows 10/11 x64. The wizard shows the license, chooses an installation folder, creates shortcuts and provides an uninstaller. On first launch, activate this computer in your browser using Google, GitHub, Microsoft or your MosaicEarth email. The setup page also accepts a MosaicEarth password. The workspace stays locked until activation succeeds. Existing valid activation is preserved during an update. It never saves the password. Activation supports two active devices; manage them on the Desktop website. The signed grant allows 30 days offline; reactivate online after expiry. Copying that grant to a different device does not activate it.

Install Docker Desktop with WSL 2 and Linux containers. Launch MosaicEarth Desktop from Start, complete activation, and choose **Install / Resume local engines** on the setup page. The account-authorized download first installs the complete interface and CPU engines, then the optional GPU engines when compatible Docker GPU access is detected, and is checked against pinned SHA-256 and Docker image IDs. Allow at least 20 GB of free space for CPU setup and another 50 GB for optional GPU setup, plus project data. Keep Docker running while processing. Reconnection resumes engine and project downloads.

The launcher and embedded Python are native Windows builds. The complete interface opens in its own Edge guest window with the MosaicEarth logo, Public Map, MyEarth, MyMosaics and Fly View. NodeODX and the interface run on a private Docker network; the interface listens only on host loopback. Neither container has access to the Docker socket. Background Docker checks do not open console windows. Version 0.4 selects GPU or CPU separately for NodeODX and OpenSplat after testing actual CUDA computation inside Docker; see [GPU requirements and fallback](GPU.md). Hardware-specific reconstruction and installer results are recorded in the [release notes](RELEASE_NOTES.md).

When MyEarth detects an earlier Desktop workspace, **Import previous local workspace** copies its project hierarchy and files into the new workspace. It leaves the earlier application and originals intact; unfinished tasks remain available to restart. This was verified with 218 data files (including 217 photos), 1.82 GB and matching SHA-256 hashes.

Project data lives in `%LOCALAPPDATA%\mosaicearth-desktop`. Uninstall from Installed apps. The uninstaller closes its idle launcher before removing the program; the workspace, downloaded Docker images and independently running Docker workspace are preserved. Stop the MosaicEarth containers in Docker Desktop if you also want to release their running resources. Back up the workspace before changing Windows profiles. The source edition can instead run directly from a Git checkout without account activation; see [Build](BUILD.md).

The account menu shows **Desktop activated for…** and **Cloud connected as…** separately. If cloud is disconnected, it offers **Connect cloud account**, with the same browser sign-in options. Activation does not connect or upload the workspace automatically. Edge guest mode isolates the application window from browser-profile synchronization; it is not the MosaicEarth account status.

Browser sign-in asks you to confirm the account and the matching code shown in Desktop. If the request expires, choose **Start again** to get a new code. Canceling does not connect the cloud or activate a computer. Current validation results and release limitations are maintained in the [release notes](https://github.com/nsicart/MosaicEarth-Desktop/blob/main/RELEASE_NOTES.md).
