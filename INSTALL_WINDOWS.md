# Install on Windows

Download `MosaicEarth-Desktop-0.3.0-x64-Setup.exe` from [Desktop](https://app.mosaicearth.app/en/Desktop), using the account that purchased Desktop or has an eligible Studio plan. Compare its SHA-256 with the published manifest. This is a native graphical NSIS wizard, with no manual `.bat` step. It is unsigned; Windows can display an unknown-publisher/reputation prompt.

Use Windows 10/11 x64. The wizard shows the license, activates the purchasing account for this computer, chooses an installation folder, creates shortcuts and provides an uninstaller. It never saves the password. Activation supports two active devices; manage them on the Desktop website. The signed grant allows 30 days offline; reactivate online after expiry. Copying that grant to a different device does not activate it.

Install Docker Desktop with WSL 2 and Linux containers. Launch MosaicEarth Desktop from Start, open **Installation and local engines**, and choose **Install local engines / resume**. The account-authorized download includes the complete interface, NodeODX and the CPU OpenSplat engine, and is checked against pinned SHA-256 and Docker image IDs. Allow at least 20 GB of free space, plus project data. Keep Docker running while processing. Reconnection resumes engine and project downloads.

The launcher and embedded Python are native Windows builds. The complete interface opens in its own Edge guest window with the MosaicEarth logo, Public Map, MyEarth, MyMosaics and Fly View. NodeODX and the interface run on a private Docker network; the interface listens only on host loopback. Neither container has access to the Docker socket. Fresh NodeODX Complete and OpenSplat Fast reconstructions have passed on physical Windows 11 with Docker Desktop. The final 0.3 graphical wizard, account activation, complete public engine download, SHA-256/image verification and automatic full-interface startup have passed on physical Windows. Background Docker checks do not open console windows. CUDA on Windows is not advertised as validated.

When MyEarth detects an earlier Desktop workspace, **Import previous local workspace** copies its project hierarchy and files into the new workspace. It leaves the earlier application and originals intact; unfinished tasks remain available to restart. This was verified with 218 data files (including 217 photos), 1.82 GB and matching SHA-256 hashes.

Project data lives in `%LOCALAPPDATA%\mosaicearth-desktop`. Uninstall from Installed apps. The uninstaller closes its idle launcher before removing the program; the workspace, downloaded Docker images and independently running Docker workspace are preserved. Stop the MosaicEarth containers in Docker Desktop if you also want to release their running resources. Back up the workspace before changing Windows profiles. The source edition can instead run directly from a Git checkout without account activation; see [Build](BUILD.md).
